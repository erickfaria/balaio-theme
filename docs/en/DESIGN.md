# Balaio design direction

[English](DESIGN.md) · [Português](../DESIGN.md)

An open notebook of ideas: simple to navigate and comfortable to read. Minimalism guides the project rather than prescribing a screen to reproduce.

## Design choices

- Warm light background, graphite text, deep green links and soft green, sand and blue cards.
- Inter for identity and interface; Newsreader for titles and articles, with device-font fallbacks.
- Three opening cards for the latest posts, followed by a steady editorial list.
- Text first in HTML order; optional images support the content.
- Subtle corners and thin separators. No shadows, carousels or decorative animations.
- A short introduction focused on curiosity and learning; blog title and description remain editable.
- Topics beside lists and a focused reading column for articles.
- On phones, a single column, wrapping menu and accessible search.

## Evolution criteria

Every element should help readers find or understand content. Develop structure, spacing and graphics from Balaio's needs with original resources. Optional features must preserve navigation and readability.

Open fonts load through Google Fonts with `display=swap`. No theme JavaScript libraries. Demo images must be original or have documented licenses.

This direction is implemented in the XML base; final appearance and compatibility still require testing inside Blogger.
