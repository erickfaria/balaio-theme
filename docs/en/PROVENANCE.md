## Balaio implementation

Balaio is an independent Blogger theme with original code under MIT. Its visual direction is in [DESIGN.md](DESIGN.md). The base includes no third-party JavaScript, images or icons. Open fonts are loaded through Google Fonts; binary font files are not bundled.

Post images and text belong to each blog's authors and retain their own rights; MIT does not license that content.

## Adding resources

Before adding a third-party resource, record its origin, author, version, license, attribution requirements and included files. Replace resources without verifiable redistribution permission with original alternatives. MIT does not override third-party licenses.

Backups, credentials and private content are excluded from distribution and commits.

No purchased fonts, stock photos, proprietary icons or third-party theme code are distributed. Default font requests deliver OFL fonts through Google Fonts; this hosting service is optional and can be replaced with self-hosting or generic device fonts. Device font availability and licensing belong to each device, not this repository. Blogger itself is an external platform and is not distributed or licensed by this project.

All included resources permit reuse and modification under their respective licenses. Keep MIT and OFL notices when redistributing applicable code or font files. The [customization guide](CUSTOMIZATION.md) explains how to remove external font requests.
